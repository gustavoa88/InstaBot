# Regras para o Codex neste projeto

## Economia de contexto
- Não analisar o repositório inteiro sem permissão.
- Trabalhar no menor conjunto possível de arquivos.
- Não abrir logs completos.
- Não ler arquivos grandes sem necessidade.
- Evitar refatorações globais.
- Fazer alterações pequenas e incrementais.

## Fluxo
1. Entender a tarefa.
2. Identificar apenas os arquivos necessários.
3. Alterar somente os arquivos relacionados.
4. Explicar resumidamente o que mudou.

## Logs
- Solicitar apenas trechos relevantes.
- Nunca utilizar docker logs completos.

## Git
- Não fazer commit automaticamente.
- Não alterar arquivos .env sem necessidade.
